## Why

Terrane's reviewed independent source has no private Git ancestry, but its operational Nix inputs and UCAN consumer profile still select private historical sources. Public contributors need anonymously fetchable, immutable dependencies without invented proof provenance.

## What Changes

- Select the independently published Octet cohorts and public Cairn assembly over HTTPS; preserve exact verifier, compiler, policy and provider artifact identities.
- Replace the stale private Trellis consumer profile with a newly measured public Terrane profile only after verifying its immutable source.
- Update current provider source bindings and deterministic projections coherently. Preserve historical archives, raw proof artifacts, license grants and signed fixture identities.
- Exercise actual proof, consumer-compatibility and anonymous-fetch paths. Record failed or unavailable lifecycle/release gates without bypassing them.

## Impact

Owner: OnixResearch Terrane maintainers. Current consumer: UCAN-facing verified-logic consumers and Terrane's own Nix verification rails. Durable capability: reproducible public source/profile admission, not a one-off checkout. Source availability and profile alignment do not establish downstream correctness or release eligibility.
